Bem-vindo(a) ao repositório do meu portfólio profissional! Sou estudante de **Ciência da Computação na UFSCar** e desenvolvo soluções de identidade visual, social media e interfaces web para marcas e pequenos negócios.

🔗 **Acesse o site online:** [Clique aqui para ver o portfólio](https://VIckt01.github.io/VIckt01-portfolio/)

## ✨ Sobre o Projeto

Este site foi construído do zero com foco em performance, acessibilidade e uma identidade visual autoral (_coquette aesthetic_), contando com microinterações e páginas dinâmicas para exibição detalhada de cada estudo de caso.

## 🛠️ Tecnologias Utilizadas

- **HTML5** semântico
- **CSS3** (Custom Properties, CSS Grid, Flexbox e animações Keyframes)
- **JavaScript (ES6+)** puro (IntersectionObserver, cursor customizado e roteamento dinâmico de projetos via URL params)

## 📂 Estrutura de Pastas

- `/index.html` — Página principal (Sobre, Serviços, Portfólio e Contato)
- `/projeto.html` — Template dinâmico para estudos de caso detalhados
- `/assets/css/styles.css` — Estilização e responsividade
- `/assets/js/main.js` — Animações e interatividade
- `/assets/js/projetos.js` — Base de dados dos projetos
